05

Try dictation once

On an Apple silicon Mac or Windows x64 or Arm64 laptop, select the microphone in the chat input. First use downloads an on-device speech model and asks for microphone access.

Say: Make the heading a little smaller. Stop the microphone and check the text. Dictation does not send the prompt until you choose to send it. You can delete this test text.

Audio recognition runs on-device by default on these desktop systems. Optional transcript cleanup sends the text to a model. Turn off optional transcript cleanup in Settings if you don't want that. Intel Mac? Typing is fine; you don't need an extra voice extension for tonight.

What this changes

Downloads a speech-recognition model and gives VS Code microphone access. Model-based transcript cleanup is a separate setting from on-device audio recognition.

How to undo it

Stop dictation, turn off built-in dictation in Settings, and revoke VS Code microphone access in your system privacy settings if you no longer want it. Disabling dictation does not delete the downloaded model.

Draft

Computer Use, with your permission

Computer Use can let the agent see a desktop app and interact with its controls. We will try a harmless task together. The app, exact setup and Windows permission path are still being checked.

On macOS, the setup asks for Screen & System Audio Recording and Accessibility access in System Settings > Privacy & Security. Screen access lets the component inspect what is shown; Accessibility allows interaction with app controls. Check the component named in the prompt before allowing either.

You grant these permissions yourself. They are broad even when the task is small, so close private material and keep the task in the agreed app. Do not turn them on until the checked setup guide identifies the component you should approve.

What this changes

Allows the approved Computer Use component to inspect and interact with desktop apps. It is separate from sharing a single integrated-browser tab.

How to undo it

Stop Computer Use, then switch off the component you enabled in both Screen & System Audio Recording and Accessibility. Turn off the feature in the checked workshop settings too. Revoking access does not undo actions or files already created.

We may install one small tool together in the room. We'll explain what it installs, its permissions and how to undo it before you approve anything.

Mode and permissions

Plan mode proposes work before implementation. Agent mode carries out the task. Autopilot keeps going and skips confirmations. These choices are separate from the workshop settings snippet.

Start in a regular folder session with Manual permissions. It follows your existing tool, URL and terminal approval settings. Actions that are not already approved ask you first. Read the request, especially when it runs a command or touches files outside your project.

Worktree sessions always use Allow all. They separate edits, not access to your machine. Autopilot also skips confirmations. Permissions and sandboxing are separate; none of these names means the agent can only touch your project.

Nothing should be sent, published, installed or purchased just because a prompt mentions it. Keep those decisions explicit. Use a small folder with fictional or public files, not private client work.

To step back, stop the session, choose Manual where supported, and review or reset any approvals you granted. Starting a new folder session is safer than assuming a worktree can be changed to Manual.

Keep spending a choice

The workshop files and this site are free. AI requests use your account's credits. Longer tasks, multiple sessions and different models can use different amounts.

You don't need another paid plan or your own API key for tonight. Do not enable additional paid usage. Adding a paid plan, a paid-usage budget or a provider key can create charges. Existing paid settings still apply, so check your account even if you are using the free month.

On GitHub, open Settings > Billing and licensing to review usage and budgets. Check your Copilot plan separately. An output-token count alone is not the cost of a complete run: input, output and cached tokens can all count.

To stop new optional usage charges, stop the work and review your additional-usage budget and any provider billing. Reducing a budget or canceling a plan does not erase charges already incurred.

GitHub Pages is public

Publishing a GitHub Pages site exposes its content to the internet. On a personal GitHub Free account, the repository used for Pages must also be public.

Before you publish, check the files, screenshots and history for names, personal information, client work, keys and private links. Deleting a file afterward does not remove copies other people may have saved.

You can unpublish Pages in the repository settings, but that cannot recall shared copies. Nothing in tonight's draft guide publishes automatically.
