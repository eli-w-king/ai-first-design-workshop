In our side-by-side test, GPT-6.1 Terra got the same results as GPT-6.2 Sol for setup, the bug fix and the screenshot edit, for a quarter to half the credits. Switching the model is part of the lesson: Terra for everyday work, Sol when the job is hard or Terra stalls.

Install Node, Git and the GitHub CLI

  1. Install Node LTS for Mac or Windows. It comes with npm and npx. If you use a version manager, select its current LTS instead.
  2. Check git --version in Terminal > New Terminal. On Mac this can offer the Command Line Tools installer. On Windows, use Git for Windows if Git is missing.
  3. Install the GitHub CLI for your system. It's called gh, not Copilot CLI. Reopen the terminal, then sign in:
Sign in to GitHub CLI
gh auth login

Use GitHub.com and Login with a web browser for your personal account. For "What is your preferred protocol for Git operations on this host?" choose HTTPS. Answer Yes to "Authenticate Git with your GitHub credentials?" The order can vary by version.

Run node --version, git --version and gh auth status. Check that gh shows the right account. At 6:10 the agent uses it to fork, set your fork as the default PR destination and later open the PR there.

What this changes

Node runs the project tools. Git saves file history. The GitHub CLI signs in on this laptop and can supply credentials for Git. Do not share sign-in codes or tokens.

How to undo it

Run gh auth logout to sign out here. To revoke access, review GitHub CLI in GitHub Settings > Applications > Authorized OAuth Apps. Remove tools using their original installer or package manager (Installed apps on Windows). Keep shared Node versions and Mac Command Line Tools if other projects need them.

First, paste the workshop settings and restart Insiders. The two entries offer Computer Use and Send Later. They do not approve commands or choose your model.

  1. In the Command Palette, use Profiles: Switch Profile to select Default. Note your previous profile. Open Preferences: Open User Settings (JSON), not Workspace Settings.
  2. Save a private backup outside your repo. Merge the entries inside the existing outer braces; add a comma after the preceding entry if needed. If a key already exists, note its old value and change it instead of duplicating it.

Turn on Computer Use

Mac: in a Copilot chat on This Computer, enter /computer on. First use downloads its plugin. Choose Set Up Computer Use. Allow Accessibility and Screen Recording (also called Screen & System Audio Recording). Quit and reopen VS Code if macOS asks.

Windows: use the same setting, restart and local Copilot chat. Windows has its own setup flow. We haven't verified its first-use permission prompts on a personal laptop. Ask a helper rather than changing system-wide permissions by guesswork.

Optional: pre-download Skola packages

Download about 450 MB at home so the venue Wi-Fi doesn't have to carry 16 copies. The command downloads Skola's package list into a temporary folder, saves the packages to pnpm's store on your laptop, then deletes the folder.

You don't need a fork yet. In VS Code, open Terminal > New Terminal and copy the command for your laptop. On the runners the download took under a minute on a Mac and a few minutes on Windows. The win is the Wi-Fi: installing the packages in the room can still take time.

Mac or Linux (Terminal)
Mac or Linux pre-download
u=https://raw.githubusercontent.com/h16nning/skola/f8d89dafb3878192f53da02f827aa55e00b83e01; d="$(mktemp -d)" && cd "$d" && curl -fsSL --remote-name-all "$u/package.json" "$u/pnpm-lock.yaml" && npx --yes pnpm@10.28.2 fetch; cd ~ && rm -rf "$d"
Windows (PowerShell)
Windows PowerShell pre-download
$u = 'https://raw.githubusercontent.com/h16nning/skola/f8d89dafb3878192f53da02f827aa55e00b83e01'; $d = Join-Path ([IO.Path]::GetTempPath()) ('skola-prefetch-' + [guid]::NewGuid()); New-Item -ItemType Directory $d | Out-Null; Set-Location $d; Invoke-WebRequest -UseBasicParsing "$u/package.json" -OutFile package.json; Invoke-WebRequest -UseBasicParsing "$u/pnpm-lock.yaml" -OutFile pnpm-lock.yaml; npx.cmd --yes pnpm@10.28.2 fetch; Set-Location $HOME; Remove-Item -Recurse -Force $d

npx.cmd avoids the PowerShell script shim. You do not need to change your execution policy.

On a first run, look for a line like Progress: resolved 985, reused 0, downloaded 985, added 985, done. If you run it again and see reused 985, downloaded 0, you're set. If it fails, leave it for the setup table.

Draft

Venue Wi-Fi and download times on personal laptops are not confirmed.

What this changes

Downloads pnpm to the npx cache and Skola packages to the pnpm store. At 6:10 the install creates node_modules in your own fork. Allow about 900 MB for the store and install together, plus caches.

How to undo it

You can leave the cache for the workshop. After the workshop, npx pnpm@10.28.2 store prune clears unused packages from the shared store, not just Skola. Use npx.cmd in PowerShell. Do not delete the whole store. To remove the npx entry, use npm cache npx ls, inspect the matching key with npm cache npx info, then use npm cache npx rm with just that key.

Runner verification: all twelve jobs passed. Six checked the app. Six checked the pre-download on Windows (PowerShell 5.1), macOS and Linux, each with and without a Node project in the home folder. Every pre-download check installed the packages offline in a fresh clone and passed the tests. Personal Windows setup still needs a rehearsal.

GitHub Pages is public

Publishing a GitHub Pages site exposes its content to the internet. On a personal GitHub Free account, the repository used for Pages must also be public.

Before you publish, check the files, screenshots and history for names, personal information, client work, keys and private links. Deleting a file afterward does not remove copies other people may have saved.

You can unpublish Pages in the repository settings, but that cannot recall shared copies. Nothing in tonight's draft guide publishes automatically.

On an Apple silicon Mac or Windows x64 or Arm64 laptop, select the microphone in the chat input. First use downloads an on-device speech model and asks for microphone access.

Say: Make the heading a little smaller. Stop the microphone and check the text. Dictation does not send the prompt until you choose to send it. You can delete this test text.

How to undo it

Screenshot and mark up

Checked against VS Code Insiders 1.148 and the docs. Not yet tested on a clean personal account.

Try native Mark Up in the chat input first. You make the visual mockup; the agent changes the real interface from that image.

  1. Capture the real interface. Where offered, use Add Context (+) > Screenshot Window or Screenshot App Window.... You can also use the OS tools below.
  2. Attach the image to the current chat input: paste with Command+V on Mac or Ctrl+V on Windows, drop the file, or use Add Context (+) > Files. Confirm its thumbnail appears.
  3. Select the unsent image, then Mark Up. Use arrows, drawing, text or crop to show your change.
  4. Select Done, then send the image with your request. Ask the agent to change the actual code and inspect the working result.

Escape applies and finishes markup; it does not discard it. Select / Move handles added annotations, not the original screenshot's pixels. Draw an arrow from the piece to where you want it to go. Use PNG or JPEG with a model that supports images, and keep private information out.

If native capture or Mark Up is missing

macOS: use Shift-Command-5 or Shift-Command-4, then edit the thumbnail or open the image in Preview's Markup toolbar. Use SDR / PNG where the format choice is offered.

Windows: open Snipping Tool or press Windows logo key + Shift + S. Use its pen, highlighter, shapes and crop. Copy the edited snip with Ctrl+C or save with Ctrl+S.

Keep an original copy. Paste or attach the edited image, not just its filename. These fallback tools annotate and crop; a layered rearrangement of the original UI is not a checked workshop step.

What this changes

Adds an image to your prompt. Native app-window capture can request screen-recording permission; it does not activate Computer Use or grant app control.

How to undo it

Undo marks before finishing, or remove the unsent attachment and attach the original again. Delete only image copies you made. Revoke capture permission separately if you no longer want it.

Mode and permissions

Checked against VS Code Insiders 1.148 and the docs. Not yet tested on a clean personal account.

Interactive, Plan and Autopilot are modes in Copilot. Interactive does the task. Plan proposes an approach first; enter /plan and review it. Autopilot keeps working and auto-approves tools.

Manual, Assisted and Allow all are permission levels. Manual follows your existing approval rules, so it does not ask before every action. Assisted uses a model to assess calls and asks about those it does not approve. Allow all runs tools without confirmation.

New Worktree sessions always use Allow all. A worktree separates files, not access to your machine. None of these modes or levels is a sandbox.

Start in a regular folder with Manual permissions and use Allow Once where offered. Only choose broader access deliberately. The settings snippet does not choose it for you.

Basic controls

Checked against VS Code Insiders 1.148 and the docs. Not yet tested on a clean personal account.

Use the labeled menu choices first. These shortcuts assume default bindings and the current steer preference. Your existing settings can differ.

Send
Starts an idle request. Mac and Windows: Enter.
Add to Queue
Waits until the current response finishes. Mac: Option+Enter. Windows: Alt+Enter, with the steer default.
Steer with Message
Redirects after the current tool finishes. Mac and Windows: Enter, with the steer default.
Stop and Send
Cancels the request and immediately sends your new message. Use the Send dropdown; no dedicated shortcut confirmed.
Stop
Requests cancellation without another message. Mac: Control+Escape. Windows: Alt+Backspace.
Send Later
Schedules one prompt, not a recurring task. Use Send Later... in the Send dropdown or Chat: Send Later... in the palette. No dedicated shortcut.
Edit and resend
Edits an earlier request. Review what will be rewound first; it does not undo external actions. Enter on a focused request, then Enter to resend, on either platform.
Attach a screenshot
Paste the image, drop a file, or use + > Files. Confirm the thumbnail is supported. Mac: Command+V. Windows: Ctrl+V.
Mark Up
Select the unsent image, choose Mark Up, then Done. Enter opens a focused image. Escape applies and finishes markup, not discard.
Switch model
Use the input's model picker. It changes the next request, not the harness. Mac: Command+Option+period. Windows: Ctrl+Alt+period.
Plan
Enter /plan with the outcome, then review the plan. Mac: Command+period opens the agent picker. Windows: Ctrl+period.

If your default is queue, Enter and Option/Alt+Enter swap meanings. Stop does not undo completed actions or cancel every pending follow-up; inspect those separately.

Before using Send Later

Choose a delay or a date and time, and check this device's time zone. A preset schedules immediately. Local Send Later needs an awake computer and an available host; it does not wake your laptop.

Use Cancel Schedule and confirm the pending entry is gone, or manage it in Automations. Turning off the setting does not cancel accepted requests. If you're unsure a schedule was created, check before retrying. Scheduled runs can use credits and act later with the session's permissions.
