The goal is one evening with a bug fixed and tested, a redesign from your own marked-up screenshot, Listen mode, three Today directions, a short narrated demo, and a live link beside your repo link for your portfolio.

Skola is an open-source, local-first flashcard app by h16nning and contributors under AGPL-3.0. This is your workshop fork, not an official release. The workshop is not affiliated with or endorsed by the Skola project.

Our premise: people love how Skola looks, and they leave in the first week. That's a design exercise, not a measured retention rate.

What gets in the way

I have five minutes before class. I fill in both sides and click Add Card on the live site, but my card isn't there when I come back. If I've already got a list of terms, typing them all again takes most of my five minutes. Skola already imports deck files. Let's start there.

Which deck should I open today? The home screen doesn't say. At the end, I get a percentage that can go over 100%, but I can't tell what I practiced. For the language learners in this brief, hearing the word is the top request. It's hard to practice saying something I've only seen in print.

What we'll change in our fork

  1. Fix the Add Card button. Write a test that fails before and passes after. Reload and study the card I just made.
  2. Bring in a file of UX flashcards. Our target: from an empty app and a ready deck file to studying the first of 40 cards in under two minutes. I can still write a card in my own words.
  3. Mark up a screenshot to redesign studying. Make it clear how far I've got and what I just finished. Add Listen mode: let me hear the visible word on demand without revealing the back. The card should still work in silence.
  4. Try three directions for a Today home. Give each the same deck and due count. Pick the one that best answers, "What should I study today?"
  5. Show the change in a 30-second narrated demo. Open a PR in my fork, publish to GitHub Pages, and open the live link in a fresh browser. Someone should be able to try my fork, find its source and see which part of this brief each change answers.

What we'll leave alone

No accounts or sync. Cards stay in this browser. No AI card generation inside Skola: an agent can help prepare a deck file outside the app. Keep Skola's license and notices, and credit the original project.

Checked Skola Pages prep, in plain words
  1. Use the checked prep revision and keep cloud initialization and its UI removed. Local cards stay in IndexedDB. Do not sign in or contact the maintainer's sync service.
  2. For a fork named skola, the app base is /skola/. The PWA start_url and scope stay under the same project path, and assets must work there.
  3. Remove the upstream CNAME step and legacy deploy scripts that create it. Do not publish the maintainer's domain.
  4. Keep LICENSE and notices. Add a dated modified-by note and link the live app to your own corresponding source. Replace reference identity and URL fields with your own.
  5. Enable Actions in your own fork, then set Settings > Pages > Source to GitHub Actions. The prepared workflow uses Configure Pages for its base path and deploys after a push to main or a manual run.
  6. Review and test on a feature branch. Check that the PR base is your own fork, then approve any merge or deployment. Open the live URL in a fresh browser and on your phone.

The local browser checks passed. Tests, type checks and /skola/ builds also pass on public-npm Windows, macOS and Linux runners with Node 22 and 26: all six jobs. Personal-laptop UI, permissions, venue Wi-Fi and a real Pages deployment are separate checks.

Windows: use PowerShell, VS Code's default terminal on Windows:

PowerShell on Windows
$env:BASE_PATH = '/skola/'
npx.cmd pnpm@10.28.2 build

npx.cmd avoids a blocked npx.ps1 shim without changing execution policy. The environment value lasts for this terminal; close it afterward or restore its earlier value.

Mac or Linux:

Mac or Linux shell
BASE_PATH=/skola/ npx pnpm@10.28.2 build

Git Bash on Windows: it rewrites /skola/ into a Windows path unless path conversion is disabled for this command:

Git Bash on Windows
MSYS_NO_PATHCONV=1 BASE_PATH=/skola/ npx pnpm@10.28.2 build

Public-npm cold installs took about 10 to 36 seconds on the runners. Venue Wi-Fi will be slower. Allow about 900 MB for the pnpm store plus node_modules, with caches using additional space.
