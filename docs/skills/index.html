Nine workflows to try

A skill is guidance an agent can use for a task. A plugin packages related skills so you can install them together. This is a draft set, not a copy of anyone's personal setup.

workshop-setup
Check your laptop and explain proposed changes before doing them.
variations
Explore different directions in separate folders or worktrees, with today's version for comparison.
demo-walkthrough
Rehearse a real flow, then record with a verified recorder or capture the screenshots you asked for. Recording needs checked tooling.
prototypes
Build in your own repo on a branch and prepare a before-and-after pull request.
pair-test
Plan a short test with a partner and keep real observations.
publish-pages
Review what would be public, then publish only after you approve.
taste
Create a taste draft from selected workspace notes through the opt-in automation, then propose updates for review.
overnight-plan
Plan bounded work with checkpoints and a clear stop condition.
job-search
Draft job-search material for you to review and send yourself.

The scope may change before release. Real recording and narration still need clean personal-laptop rehearsals. Voice can follow the same idea later; no voice template is included.

What it installs

The draft plugin adds instructions and automation templates, including Keep my taste current. That template is intended to build a personal taste skill from references you choose. The draft starts with a Manual trigger and an explicitly chosen Run now before any optional weekly schedule. Review the selected sources, output and cost first. The exact workshop flow is still being checked. Installing a template does not enable a recurring job.

It includes instructions, references, an inert optional recording helper, and three opt-in automation templates. It bundles no hooks or MCP servers and does not install the helper's dependencies. It does not silently change settings, turn on background work or grant broader permissions. A skill may suggest a setup change; review the action before approving it.

Skills are instructions, not a sandbox. Normal permissions still matter, and AI requests still use credits. Nothing is sent or published unless you choose to do that.

Install in VS Code, after release

  1. Open the Copilot harness in VS Code Insiders and run Chat: Open Customizations.
  2. In Browse, open the source menu, then Configure Marketplaces > Add Marketplace. After release, enter eli-w-king/ai-first-design-workshop.
  3. Select design-workshop, review the README and included skills, then choose Install and approve the trust prompt only if you agree.

If that Browse interface is unavailable, use Plugins > Browse Marketplace where offered, or the documented CLI route below. Do not invent settings to force the install.

The release will use the design-workshop plugin in eli-w-king/ai-first-design-workshop. This link is shown as text until the plugin is available:

After release: install link
vscode-insiders://chat-plugin/install?source=eli-w-king%2Fai-first-design-workshop&plugin=design-workshop

After installing, start a fresh session and check that all nine skills appear. Try check my setup first, then inspect the proposed actions before accepting changes.

Install in Copilot CLI, after release

This is optional. If you already use Copilot CLI, add the workshop marketplace and install the named plugin:

After release: terminal commands
copilot plugin marketplace add eli-w-king/ai-first-design-workshop
copilot plugin install design-workshop@ai-first-design-workshop
copilot plugin list

The first command registers a catalog. The second downloads the plugin. The third lets you confirm what is installed. Review the plugin contents before you use it; this page does not install anything.

If you do not have the CLI, you can stay in VS Code. Installing another client is not required for the workshop.

Remove it when you're done

In VS Code, run Chat: Open Customizations, open Plugins, choose design-workshop, then Uninstall.

If you installed it through Copilot CLI, use:

Terminal commands
copilot plugin uninstall design-workshop@ai-first-design-workshop
copilot plugin marketplace remove ai-first-design-workshop

Removing the plugin does not undo files you made, settings you separately approved, or automations you deliberately enabled. Stop and remove those separately if you no longer want them.
