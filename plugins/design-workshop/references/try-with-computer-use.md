# Let the agent try your app

This is a handoff to the host's supported Computer Use capability, not a bundled desktop-control tool. Keep screenshot markup separate: the person editing an image is not Computer Use.

1. Use the checked [Get ready guide](https://eli-w-king.github.io/ai-first-design-workshop/get-ready/) for availability, activation, any first-use download and the person's own OS permissions. Ask before installing a PWA or any helper. Never grant permissions or change settings on the person's behalf without an explicit okay.
2. Confirm the exact task-owned app or browser window and the person's fork/local URL. Upstream services must already be inert. Do not operate the original maintainer's app, sign in, or switch to another person's window.
3. Give one bounded task with an approved local input, such as importing the named deck file through the actual file picker and trying one feature. Show what will change. Writing a deck file alone is not permission to import it.
4. Use the actual Computer Use tools when they are available and approved. Do not substitute DOM automation and call it native app control. Do not touch the isolated window, files or server that another session is recording.
5. Import once, inspect the preview and verify the resulting count and a few cards. If completion is ambiguous, inspect the state before trying again so the deck is not duplicated. Use only the selected file; no browsing through unrelated folders.
6. If the feature makes sound, confirm the app actually plays it. A narration track or a screenshot of a Listen button is not proof. Report audio checks that were unavailable.
7. On an unexpected sign-in, purchase, destructive action or wider permission request, stop. The person decides. If Computer Use is unavailable, explain the blocker and offer a distinctly labeled browser/manual fallback only with agreement.

Finish one-off control helpers, but keep the app/dev preview you started available while the person or queued follow-ups are still working. Give its URL/port and Ctrl+C or its owned process stop control. Stop it when the person is done or asks; never kill a process someone else started. Follow Get ready's separate off and OS-permission steps if the person wants to revoke access; do not assume closing a chat revokes it. Removing an installed app, deleting imported cards or changing activation settings requires approval.
